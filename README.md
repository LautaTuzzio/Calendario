# Calendario Interactivo

Un calendario moderno con animaciones suaves y funcionalidades para gestionar eventos.

## Caracteristicas

- Interfaz moderna y amigable
- Visualizacion de dias festivos
- Gestion de eventos
- Animaciones suaves en:
  - Dias al cargar
  - Dia actual (animacion de pulso)
  - Dias festivos (animacion de rebote)
  - Dias con eventos (animacion de aparicion)
  - Dia seleccionado (animacion de escala)
- Soporte para eventos persistentes (localStorage)
- Responsive design

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

## Como Usar

1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. Navega entre meses usando los botones de flecha
4. Haz clic en un dia para:
   - Ver eventos existentes
   - Agregar nuevos eventos
   - Seleccionar el dia

### Dias Festivos Predefinidos

- 1 de Enero: Ano Nuevo
- 1 de Mayo: Dia del Trabajo
- 25 de Diciembre: Navidad
